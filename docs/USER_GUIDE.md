# 用户指南

## 安装和第一次启动

运行 Windows x64 Setup，按当前用户安装，不需要管理员权限，也不需要另外安装 .NET。通过开始菜单 AI Investment Workbench 启动。首次没有账户时显示向导，50 万 CNY 和目标比例只是可修改示例。取消后仍可从总览创建账户。

窗口左侧为导航，右上角切换账户。证券、观察清单和研究为共享资料；交易、组合、日志和定期复盘按账户。深浅主题在设置即时切换。小屏幕和高缩放时外层滚动条提供完整页面访问；键盘 Tab / Shift+Tab 移动焦点，表格方向键选择，按钮 Enter/Space 操作，编辑窗口 Escape 取消。

## 完成一次研究到决策的闭环

1. 证券库新增证券，填写代码、交易所、市场、币种与类型。
2. 在观察清单添加候选对象，维护阶段、优先级、理由和下一步行动。
3. 财务页录入或 CSV 导入指标，保留期间、币种、来源及估算标记；来源文件支持 TXT、Markdown、CSV、可提取文本 PDF，不支持 OCR。
4. 研究页编辑章节、来源等级与用户评分。保存后可继续修改；AI 评分不会自动产生。
5. 逻辑页建立 Thesis、假设和 Kill 条件，填写可以核验的阈值、方向及证据。Triggered 提醒不自动替你宣布逻辑无效。
6. 估值页建立 Bear/Base/Bull，检查数据日期、假设和当前价格日期。PE、倍数、DCF、反向估值均由代码计算。
7. 组合页记录真实买卖或现金交易，持仓与现金随账本变化。没有行情 API，手工价格须填写日期。
8. 风险页检查集中度和多标签暴露，填写加仓/退出清单。保存决策不会下单，可生成待确认 Journal 草稿。
9. 日志与复盘页记录理由和预期；更正保留原版本。生成周/月/季度资料后，由你填写实际结果、逐项假设评估、结论和最终选择。
10. 需要 AI 时，在设置配置 Provider、模型与加密密钥，再明确启动公司研究或 Thesis Challenge。可取消，异常不会阻断本地功能。
11. 设置中“立即备份”，退出后再启动，资料保留。恢复步骤见 BACKUP_AND_RESTORE.md。

## 导出

设置 → 导出资料，可输出 Portfolio CSV、Transactions CSV、Financial Metrics CSV、Journal CSV、Research JSON/Markdown、Thesis Markdown、Quarterly Review Markdown。Journal 包含原始及更正历史；季度批量导出最新保存版本，单个旧版本可在复盘历史页导出。研究 JSON 包括章节、来源、指标与评分，不含 API Key。

Portfolio、交易、Journal、季度复盘按当前账户；财务可选证券或全部，研究与 Thesis 必须选证券。CSV 是 UTF-8 BOM、逗号分隔、小数点数字，文本公式起始符会加单引号保护；因此导出用于查阅/归档，不保证可作为原样往返导入模板。标准导入格式见 CSV_IMPORT.md。

## Demo

设置 → 创建 / 打开 Demo，在独立窗口使用虚构证券和报价。窗口标题和侧栏持续显示 DEMO；它不是实时行情，不使用正式数据库。先关闭 DEMO 窗口，再在正式窗口 Reset / Delete Demo Data。重置和删除前保存 Demo 数据库副本，正式账户不受影响。

## 遇到错误

界面显示简短原因与处理方向，详细类型/堆栈写本地日志。文件不存在时重新选择；磁盘满或权限不足时先解决磁盘/目录问题。不要手动删除正式数据库来解决启动错误。升级或恢复失败时原库保留，可查看 BACKUP_AND_RESTORE.md。AI 错误在 AI 页面分类显示，检查模型、密钥、网络或服务余额；不要把密钥发入日志反馈。

关于区显示版本、.NET、数据库/日志/备份位置及 AI Provider 状态。卸载仅移除程序与快捷方式，保留用户资料。换机需另存数据库、附件与资料文件；密钥重新设置。
