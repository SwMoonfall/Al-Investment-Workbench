# 路线图

| 阶段 | 状态与范围 |
|---|---|
| Phase 0 | 已完成：分层 Solution、SQLite、迁移、导航、主题、日志、异常、基础测试 |
| Phase 1 | 已完成：账户向导、证券 CRUD、六类交易、交易驱动持仓、手工报价、Dashboard、观察清单、CSV 原子导入 |
| Phase 2 | 已完成：公司研究、财务指标/趋势/CSV、来源与 PDF 文本提取、研究评分、可配置会计关注规则、全局搜索 |
| Phase 3 | 已完成：可证伪 Thesis、假设、用户专属 Kill 条件、状态确认、完整版本历史、复盘提醒 |
| Phase 4 | 已完成：确定性 PE / EV/EBITDA / EV/FCF / DCF、反向增长与利润率求解、三情景比较、输入日期与持久化 |

当前交易仅追加，没有修改/删除/冲正 UI。后续扩展不能通过直接修改仓位余额破坏历史一致性。外汇、空头、融资和公司行动需单独设计。当前无实时行情、无券商交易；AI 调用仅在用户配置后明确启动。每阶段在同一项目基础上增量交付。

后续待规划：更多 AI Provider、实时行情/财务来源、研究版本历史、全文索引、附件备份、组合历史纠错/冲正、备份恢复界面。




Phase 5 已完成：证券多风险标签、暴露聚合、集中度、Risk Dashboard、仓位规划、加仓/退出清单及不可覆盖的决策历史。后续统计相关性、穿透式基金暴露、汇率风险模型需独立设计。


Phase 6 已完成：官方 Responses 适配、Windows DPAPI 密钥、AI 设置与连接测试、15 个提示词、有限上下文、结构化输出、不可覆盖审计、十步公司研究与反证流程。单元测试无真实网络 AI 调用。


Phase 7 已完成：原始投资日志与更正历史、决策草稿确认、周/月/季度资料和人工结论、季度复盘待办、独立 AI 分析与投资行为统计。缺失历史和统计口径明确披露；不自动执行决策。


Phase 8 已完成的实现：每日备份与 7 份保留、确认恢复并重启安全替换、副本迁移与失败保护、八类导出、独立 Demo、版本/路径说明、图标与 Windows x64 自包含发布及安装器。最终实测结果见发布报告。
