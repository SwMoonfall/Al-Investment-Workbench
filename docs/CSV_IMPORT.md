# CSV 导入第一版

文件要求：UTF-8（允许 BOM）、逗号分隔、首行为不重复且非空的表头。支持双引号包裹字段、字段内逗号/换行以及 `""` 转义引号。最多 5 MB / 10000 条数据；预览前 100 条，但验证与导入处理全部记录。

日期为 `yyyy-MM-dd`，不能晚于今天。数字使用小数点，不包含千分符、百分号或科学计数法；避免把 `1,2` 错读为 12。枚举英文大小写不敏感。RMB 自动规范为 CNY。

## 流程

1. 在右上角选定目标账户（Security 导入不依赖账户）。
2. 选择导入类型和 CSV 文件，核对预览。
3. 每个目标字段选择对应表头；源表头可以是中文或自定义名称。标记 * 的字段必须映射。
4. 点击“验证整批数据”。该步骤使用与正式导入相同的数据库校验路径，但回滚所有写入。
5. 全部通过后，“确认导入”可用。导入时再次校验，在一个 SQLite 事务中提交。
6. 任何错误均为整批失败，不会只写入一半。结果包含记录编号或整批核算错误，可保存为文本报告。

修改文件、类型、映射或账户后须重新验证。后台执行导入，过程中不要退出应用。成功批次保存标准化内容指纹，相同类型/账户/内容不能重复导入；这不是跨文件的逐笔交易去重，内容改变仍需用户核对。

## Security

必填：Ticker、CompanyName、Market、Exchange、Currency、SecurityType。

可选：Sector、Industry、Country、ISIN、Notes。

- Market：ChinaA / HongKong / US / Other。
- SecurityType：Stock / Etf（也接受 ETF）/ Other。
- Exchange：显式填写，如 XSHG、XSHE、XHKG、XNAS。
- 同一交易所与证券代码唯一。导入只新增，不覆盖已有证券资料；重复行会导致整批失败。
- ISIN 为空或 12 位字母数字；不验证代码真实性。

## Positions

全部必填：Ticker、Exchange、Quantity、AverageCost、Date、Currency。

证券必须已存在，币种须匹配当前账户。每行转换为一笔 Buy 交易：数量 × AverageCost 从现金扣除，备注标记为 CSV 期初持仓。AverageCost 应包含原有成本费用，附加手续费为零。

这是期初买入导入，不是仓位覆盖或余额对账。账户初始资金应足以支付期初持仓，导入后现金 = 初始资金 - 买入成本（考虑其他交易）。不要同时重复导入这些持仓的原始买入交易。

## Transactions

始终必填映射：Type、Date、Currency。其他字段按交易类型校验；未映射的数字字段默认 0。

| Type | 证券字段 | Quantity / Price | Amount | Fees |
|---|---|---|---|---|
| Buy | Ticker + Exchange 必填 | 均为正 | 0 | 非负，加入买入成本 |
| Sell | Ticker + Exchange 必填 | 均为正 | 0 | 非负，从卖出现金扣除 |
| Deposit | 均留空 | 均为 0 | 正数 | 非负，扣除费用 |
| Withdraw | 均留空 | 均为 0 | 正数 | 非负，额外扣除费用 |
| Dividend | 可同时填写证券标识或留空 | 均为 0 | 正数 | 非负，从分红中扣除 |
| Fee | 均留空 | 均为 0 | 正数，费用总额 | 必须 0，防止重复计费 |

Notes 可选。引用证券需预先建立。不同币种拒绝导入；不做外汇换算。整批与原历史一起按发生日期排序，同一天按原录入顺序及本文件行顺序处理，任一历史时点超卖或现金不足均拒绝整批。

## 示例

`docs/samples/securities.csv`、`positions.csv`、`transactions.csv` 是虚构数据，可在新建 CNY 测试账户中按上述顺序导入。它们演示两类证券、期初仓位与全部六种交易，不代表真实投资建议。正式账户导入前请核对币种、字段映射和是否存在重复历史。
