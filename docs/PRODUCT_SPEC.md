# 产品规格 · Phase 1 Portfolio MVP

核心目的不是自动荐股。AI 是研究助理，最终投资决策由用户完成。第一版不提供券商自动交易。本阶段完成本地投资记录闭环，不调用真实 AI API 或行情接口。

## 账户

无账户时显示初始化向导。示例：500000 RMB（保存为 CNY）；ETF 40%、主动 40%、观察/试验 10%、现金 10%，默认单仓上限 10%。这些数值均为用户可修改的示例。四类目标合计 100%，上限/目标在 0–100% 内。

支持多个账户和当前账户选择。账户保存名称、本位币、初始资金、当前现金与目标配置。CurrentCash 由交易计算。已创建账户本位币不可变，更换币种使用新账户；修改初始资金重放历史，不能导致透支。账户名称和目标可编辑。

## 证券

支持 Stock、Etf、Other；市场 ChinaA、HongKong、US、Other。新增、详情、编辑、删除、搜索与市场过滤。资料包括代码、公司名称、市场、交易所、币种、类型、板块、行业、国家、可选 ISIN、备注。交易所+代码唯一。有关联交易、仓位或观察记录时阻止删除；已有报价/投资记录时不能修改币种。

## 交易与仓位

支持 Buy、Sell、Deposit、Withdraw、Dividend、Fee，独立保存日期、数量、价格、现金金额、手续费、币种、备注和可选证券。交易按日期、同日录入顺序核算，允许回溯补录，拒绝历史任意时点透支或超卖。

投资组合展示总资产、现金、证券市值、未实现浮盈亏、资产数量、持仓表与交易历史。持仓有数量、均价、市值、权重、浮盈亏及百分比、目标、上限、人工报价和价格日期；未报价项显示“成本暂估”。支持表头排序、搜索、按类型或超限过滤、新增交易、编辑价格/权重、查看证券。

## 总览

显示当前账户 Total Assets、Cash、Invested Assets、Unrealized PnL、Position Count 和全局 Watchlist Count，列示 Top 5 持仓与四类资产的实际/目标配置。没有虚构研究提醒或自动推荐功能。

## 观察清单

全局清单，每证券一条。支持新增、编辑阶段/优先级、理由、下一步、研究日期、风险、备注，移出清单，按阶段过滤、关键词搜索与表头排序。阶段依次包含 Candidate、Screened、Researching、DeepResearch、Ready、Rejected、Invested；不会自动推断投资决策。

## CSV

选择文件 → 预览 → 字段映射 → 整批验证 → 确认导入 → 保存结果/错误报告。支持 Security、Positions、Transactions。失败整批回滚，正式导入再次校验。Positions 导入转为买入历史并扣现金，不覆盖旧仓位。

## 验收

可创建 50 万账户、增加证券、录入多笔交易形成持仓、更新手工价格、查看总览和配置、维护观察清单、导入三类 CSV。关闭重启后账户、现金、历史、持仓和观察记录仍存在。构建、业务测试、数据库升级和 WPF 流程检查通过。

## Phase 2 研究与财务

已提供公司研究十章节、来源及全文、财务指标 CRUD/CSV、年度/季度/TTM 筛选、收入/毛利率/营业利润率/FCF 趋势、确定性公式、可配置会计关注规则、用户优先的研究评分、跨模块本地搜索。没有真实 AI 评分或基础财务公式的 AI 计算。来源等级 1–6 显示在列表与选择器；数据不足不伪装成正常结论。

文件支持 TXT、Markdown、CSV、PDF，保存原路径与提取文本；扫描 PDF 明确提示当前不支持 OCR。研究正文明确保存并检查版本，CSV 财务数据整批事务提交，关闭重启后全部研究资料仍保留。具体口径、工作流程及限制见 RESEARCH_AND_FINANCIAL.md。

## Phase 3 投资逻辑

已实现 Thesis、研究假设、用户专属 Kill Conditions、完整版本历史、人工状态确认及复盘入口。触发条件自动提示 Warning，系统不自动 Invalidated，不生成交易。用户可比较旧版本与当前版本；同证券保留多个历史 Thesis，仅一个当前逻辑。

Dashboard 汇总到期复盘，Portfolio / Watchlist 展示关联证券逻辑状态与复盘日期。Green / Amber / Red 与文字一起表达状态；未知值或缺少条件不标成安全。操作与验收口径见 INVESTMENT_THESIS.md。

## Phase 4：估值
用户可建立五种独立估值模型，比较 Bear/Base/Bull，复制 Base 后修改；使用当前价格反推收入 CAGR 或稳定营业利润率。输入标注 Actual / Assumption，输出标注 Calculated，展示来源、假设、价格日期。DCF 为现值，年化不适用。所有估值公式与求解均由代码执行，LLM 不承担计算。

## Phase 5：风险工作台
风险总览显示含现金分母的多标签暴露、个股及单证券集中度、Top 3/5、行业/市场集中度、触发条件、会计高关注与 Thesis Warning。支持自定义标签、四参数仓位规划与加仓/退出清单。必须保留每次用户选择、理由和当时快照，不自动创建交易。相关性上升由用户核对，当前不提供 VaR。

## Phase 6：AI 研究
可选官方 OpenAI Responses 研究助理，模型由用户配置。15 个可编辑/复制/恢复的模板，标准六类信息及六类反证输出；Thesis Challenge 保留三种反对者视角。十步公司研究可开始、取消、查看进度，结果逐步自动保存并可导出。AI 只能提出建议，不能修改投资数据；财务与估值计算仍由代码执行。API Key 使用 Windows 当前用户加密，默认关闭 AI。详见 AI_INTEGRATION.md。

## Phase 7：Journal & Review
记录当时的投资理由、预期和信心，保留原始日志与更正历史。加仓/退出决策只能生成待确认草稿。定期复盘区分历史证据与当前快照，季度假设评估和投资决策由用户完成。AI 只生成独立分析，不用短期亏损自动判断决策错误，不进行心理诊断。首页呈现季度待办、逻辑警告、最近日志与 AI 复盘。详细口径和限制见 JOURNAL_AND_REVIEW.md。
